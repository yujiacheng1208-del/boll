# 天机滚珠

首个游戏场景：一枚发光滚珠持续沿透视道路滚向远方。

## Build an APK

1. Open `android-game` in Android Studio (install Android SDK Platform 35 when prompted).
2. Choose **Build > Build APK(s)**.
3. The debug APK will be under `app/build/outputs/apk/debug/app-debug.apk`.

The game currently has no input; it is the requested continuous rolling prototype and a clean basis for obstacles, steering, scoring, and sound.
